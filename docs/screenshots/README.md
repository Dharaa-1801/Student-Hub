# StudentHub screenshot evidence

Save final website testing screenshots in this folder using the names listed
in [`../README.md`](../README.md).

## Capture settings

- Use the same browser and zoom level for all desktop captures.
- Include the browser address bar for local URL evidence, but do not expose
  passwords, cookies, or private student data.
- Capture desktop pages at approximately 1280x720 or wider.
- Capture mobile navigation at approximately 390x844.
- Use PNG format and descriptive names.

## Required evidence

1. `01-home.png`
2. `02-student-login.png`
3. `03-student-dashboard.png`

These files are intentionally not generated automatically because they must
show the actual browser/database state from the final environment. This keeps
the evidence honest and prevents screenshots from containing stale or
unavailable data.
